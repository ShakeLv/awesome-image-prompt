## How to use

1. **Copy** any `prompt_en` (or `prompt_zh`) and paste it into your favourite `gpt-image-2` client.
2. **Or generate it instantly** with the OpenAI-compatible API on [API Models](https://apimodels.app/gpt-image-2-prompts) — `gpt-image-2-all` starts at **$0.005 / image**:

```bash
curl -X POST https://apimodels.app/api/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "gpt-image-2-all", "prompt": "<paste a prompt here>", "resolution": "1K", "quality": "low", "aspect_ratio": "1:1" }'
```

Swap the subject, style or colours and regenerate — these prompts are built to be remixed.

## How to write great GPT Image 2 prompts

Distilled from analysing all 955 prompts (the % is how often each technique actually appears):

1. **Name a color palette** (78%) — 2–3 concrete colours or a named palette.
2. **Direct the light** (~80%) — soft/diffused for products, dramatic high-contrast for thumbnails/posters.
3. **Set the camera angle** — 45°/three-quarter, overhead flat-lay, centered hero, macro close-up.
4. **Write the exact on-image text** (30%) — put the literal headline/label/price in quotes.
5. **Use concrete props & materials** — "frosted glass", "kraft pouch" + 1–2 supporting props.
6. **Match aspect ratio to platform** — 1:1 / 4:5 e-commerce & social, 16:9 thumbnails, 2:3 posters.

**Formula:** Subject (material/brand) + setting + props + lighting + color palette + style + on-image text (in quotes) + aspect ratio.
